# 🌞 بوت الرد الآلي لصفحة مركز شمس رؤيا

وكيل ذكي (Claude) يرد تلقائياً على صفحة فيسبوك:

| الميزة | التفاصيل |
|---|---|
| **ماسنجر** | يرد على الرسائل الخاصة كمحادثة طبيعية، مع مؤشر "يكتب..." |
| **التعليقات** | يرد على تعليقات المنشورات رداً عاماً قصيراً (ويقرأ نص المنشور ليفهم السياق)، ويتجاهل التعليقات المزعجة والإشارات |
| **الذاكرة** | يحفظ سجل محادثة كل شخص وملاحظات يستنتجها عنه (اسمه، الخدمة التي تهمه...) ويكمل معه من حيث توقف |
| **الاستنتاج** | يفهم المقصود من الرسالة ويجيب من معلومات المركز فقط، ولا يخترع أسعاراً أو مواعيد |
| **التحويل لموظف** | عند الشكاوى أو طلب التحدث مع إنسان أو سؤال لا يعرف جوابه: يتوقف عن الرد على هذا الشخص ويُبلغ المسؤول |
| **تدخّل الموظف** | إذا رد أحد المشرفين يدوياً من صندوق الرسائل، يتوقف البوت عن الرد على هذا الشخص تلقائياً (12 ساعة افتراضياً) |

---

## 1) أدخل معلومات المركز (الأهم)
افتح `knowledge/center-info.md` واملأه: الخدمات، الأسعار، المواعيد، العنوان، طريقة الحجز، الأسئلة الشائعة.
البوت يعتمد على هذا الملف **فقط**؛ أي شيء غير مكتوب فيه يحوّله لموظف بدلاً من التخمين.
أي تعديل على الملف يُطبَّق مع الرسالة التالية دون إعادة تشغيل.

## 2) جرّبه محلياً بدون فيسبوك
```bash
cd shams-roya-bot
npm install
cp .env.example .env          # ضع ANTHROPIC_API_KEY على الأقل
npm run chat                  # محادثة كأنها ماسنجر
npm run chat -- comment       # محاكاة تعليقات عامة
```

## 3) إعداد تطبيق فيسبوك (Meta)
1. ادخل <https://developers.facebook.com/apps> ← **Create App** ← نوع **Business**.
2. أضف منتج **Messenger** ← في *Access Tokens* اربط صفحة «مركز شمس رؤيا» وانسخ **Page Access Token** إلى `FB_PAGE_ACCESS_TOKEN`.
3. من *Settings → Basic* انسخ **App ID** و **App Secret** إلى `FB_APP_ID` و `FB_APP_SECRET`.
4. انشر البوت (الخطوة 4) ثم في *Messenger → Webhooks*:
   - Callback URL: `https://<رابط-البوت>/webhook`
   - Verify Token: نفس قيمة `FB_VERIFY_TOKEN`
   - اشترك في الحقول: `messages`, `messaging_postbacks`, `message_echoes`, **`feed`** (للتعليقات)
5. الصلاحيات المطلوبة: `pages_messaging`, `pages_read_engagement`, `pages_manage_engagement`, `pages_manage_metadata`, `pages_read_user_content`.
   في وضع التطوير يعمل البوت مع مشرفي الصفحة والمختبرين فقط؛ للعمل مع الجمهور قدّم التطبيق لـ **App Review** وفعّل **Live**.

## 4) النشر (مثال: Render)
- New → **Web Service** ← هذا المستودع ← **Root Directory**: `shams-roya-bot`
- Build: `npm install && npm run build` — Start: `npm start`
- أضف متغيرات `.env.example` في *Environment*.
- أضف **Persistent Disk** على المسار `/data` واجعل `DATA_DIR=/data` حتى لا تضيع الذاكرة عند إعادة التشغيل.
- أو عبر Docker: `docker build -t shams-roya-bot . && docker run -p 3000:3000 -v bot-data:/data --env-file .env shams-roya-bot`

## ملاحظات
- تُحفظ الذاكرة في `data/customers/*.json` (ملف لكل شخص). لمسح ذاكرة شخص احذف ملفه.
- فيسبوك يعطي نفس الشخص معرّفاً مختلفاً في التعليقات عنه في ماسنجر، لذلك ذاكرة التعليقات منفصلة عن ذاكرة الرسائل.
- تنبيهات `ADMIN_PSID` تصل فقط إن كان المسؤول قد راسل الصفحة خلال آخر 24 ساعة (قيود ماسنجر). لمعرفة PSID الخاص بك: راسل الصفحة ثم ابحث عن معرّفك في سجل الخادم.
- النموذج الافتراضي `claude-opus-5-5` مع `effort=low` لسرعة الرد؛ ومفعّل خيار التحويل التلقائي لنموذج بديل إن رفض النموذج طلباً.
